## Admission checklist

For each candidate, record exact image/source URLs, author/rights holder, permission or file-level licence, retrieval/permission dates, processing/change notes, actual local-file hash/dimensions and matching garment identity. Review frontal framing, visibility and reference category. Keep seller/product metadata separate from photo provenance.

Progression: **candidate → live-reviewed** only after an approved generated-output visual assessment is recorded for the exact reference. Poor/missing references stay **blocked**; API success alone does not promote them. Never recolour/substitute a different garment to fill coverage.

Seller actions additionally require seller name, HTTPS exact-item URL, `exactItemVerified:true`, product verification date and separate image-permission verification date. These metadata assertions require real supporting evidence. No current entry has verified seller metadata; no fabricated prices, availability or buy links.
